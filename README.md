# SENTRY-CIB console

Single-file browser console for early detection of coordinated review campaigns.

Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 5178

`sample_events.jsonl` can be loaded with "Replay data...". It holds 2,630 synthetic events with one planted ring.

Tier 0, Tier 1 and the Hawkes fit follow the manuscript's equations. The temporal graph network, sentence-embedding index and learned gate are labelled stand-ins. All results come from synthetic streams.
